# Spectron avatars

The current collection uses frontal, head-and-shoulders portraits of human–cyber hybrids. Each role has an assigned opaque background. There are no glitch effects.

| Role | Avatar | Background |

| Junior engineer | [junior-engineer-cyberpunk.png](./junior-engineer-cyberpunk.png) | Green, target `#16B84E` |
| QA engineer | [qa-engineer-cyberpunk.png](./qa-engineer-cyberpunk.png) | Amber, target `#E9A21B` |
| Manager | [manager-cyberpunk.png](./manager-cyberpunk.png) | Blue, target `#175FE8` |

| Copywriter | [copywriter-cyberpunk.png](./copywriter-cyberpunk.png) | Coral, target `#EB614F` |

All PNGs are 1254 × 1254. The Senior engineer has a close buzz cut. The Junior engineer is a teenage boy with short tousled hair and light cybernetic implants. The QA engineer is a gray-haired man with a single cybernetic optical eyepiece. The Manager is an adult Asian woman with short hair and a fitted face mask. The Code reviewer is an adult woman with long hair and VR glasses. The Copywriter has a copper bob, round smart glasses and a subtle temple implant.

Public URLs and role-specific background colors are in [cyberpunk.json](./cyberpunk.json). Use `object-fit: cover` for circular or rounded-square avatars.
